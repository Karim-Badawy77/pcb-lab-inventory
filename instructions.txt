- go to C:\Program Files\MongoDB\Server\<MongoDB_Version>\bin
- open mongod.cfg file and change the following line:
    #replication:
    #  replSetName: "rs0"
    to
    replication:
        replSetName: "rs0"

- cd .../pcb-lab-inventory
    make .env file
    shell run npm install
    shell run npm start

- cd .../pcb-lab-inventory/frontend
    modify config.js file in public folder to change API_BASE_URL to IP address of server instead of localhost
    shell run npm install
    shell run npm start

- for everyday use:
    double check configuration in config.js file in frontend/public folder, then run the following command in PowerShell in root directory of the project:
        if ((Get-Service MongoDB).Status -ne 'Running') { Start-Service MongoDB }; if ((Get-Service MongoDB).Status -eq 'Running') { Start-Process powershell -ArgumentList "-NoExit", "-Command", "npm start"; Set-Location .\frontend; npm start }

- for more instructions on how to use the project, please refer to the README.md file in the project root directory and the frontend directory.
