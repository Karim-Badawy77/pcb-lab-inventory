- go to C:\Program Files\MongoDB\Server\<MongoDB_Version>\bin
- open mongod.cfg file and change the following line:
    #replication:
    #  replSetName: "rs0"
    to
    replication:
        replSetName: "rs0"

- cd .../pcb-lab-inventory
    make .env file
    shell: npm install
    shell: npm run build
    shell: npm start

- for everyday use, you can run the following shell command in the project root directory:
    shell: npm start

- for more instructions on how to use the project, please refer to the README.md file in the project root directory.
